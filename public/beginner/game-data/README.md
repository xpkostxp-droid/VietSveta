# Данные уроков для игр

Файлы генерируются из актуального контента сайта. Не редактируйте JSON вручную.

- `index.json` — список уроков, имена файлов, количество записей и SHA-256 каждого файла.
- `lesson-01.json` … `lesson-10.json` — отдельный файл на каждый урок; новые уроки из `lessons.ts` добавляются автоматически.

## Формат версии 1

| Поле | Содержимое |
| --- | --- |
| `schemaVersion` | Версия формата: 1 |
| `lessonId`, `number`, `title` | Постоянный ID, номер и название урока |
| `cards` | Все исходные карточки урока с ID, переводами и картинками |
| `words` | Слова и фразы карточек, словарей теории и однозначно размеченных двуязычных фрагментов; `vi`, `ru`, дополнительные исходные поля и `source` |
| `grammar` | Блоки `pattern`, а также таблицы со столбцом «Схема» или «Маркер», целиком с пояснениями |
| `examples` | Примеры конструкций, примеры слов, полные фразы карточек/словарей, реплики, явные пары из таблиц и текста; `vi`, `ru`, `tokens`, `source` |
| `dialogues` | Диалоги теории с исходными говорящими; в уроке 9 также `sentence-bank` из игры |
| `theory` | Все исходные блоки теории, включая таблицы, примечания, советы и текст; `null`, если теории нет |

Пустой массив означает отсутствие материала соответствующего типа, а не ошибку.
Карточки сейчас есть в уроках 2–10; у урока 1 используется теория. Урок 9 объединяет обе группы карточек.
Неоднозначный текст не превращается в выдуманные переводы: он остаётся в `theory`.
Генератор переносит учебные формулировки как есть и не исправляет спорные места конспектов.
Повторы между источниками и разные значения одного слова сохраняются; потребитель может
объединять точные пары `vi` + `ru`, но не должен объединять записи только по `vi`.

`source.file` — путь исходного файла в репозитории; `source.pointer` — позиция
в экспортированной структуре (индексы от нуля) либо постоянный ID карточки.
Пути картинок относительны корню сайта, а не каталогу JSON.
`tokens` — слова/числа без пунктуации, с сохранением порядка, повторов и диакритики.
Это вьетнамские слоги, разделённые пробелами, а не лингвистическая сегментация сложных слов.
Не используйте словарные записи с вариантами через `/` или шаблоны с `…` как единственный
правильный ответ без дополнительного выбора конкретной формы.

## Обновление и проверка

```sh
npm ci
npm run build
npm run check:game-data
npm test
```

Генератор читает `src/content/lessons.ts`, `cards.ts`, теорию импортированных уроков
и `games/dialogues.ts`. TypeScript компилируется установленным `typescript`; новые
зависимости не нужны. Vite `BASE_URL` для картинок заменяется на `./`.
Если появится отдельный игровой банк другого урока, зарегистрируйте его в `dialogueSets`
в `scripts/load-content.mjs`. Диалоги внутри теории находятся автоматически.

Генерация запускается только при `npm run build` через `prebuild`.
`npm run dev`, `npm run preview` и работа сайта генератор не запускают.
Существующий workflow публикации собирает проект и публикует свежие JSON в GitHub Pages.
Отдельного workflow генерации и автоматических коммитов нет. Для обновления JSON
в самом репозитории включите результат сборки в обычный коммит.

JSON — отдельные статические файлы для внешнего потребителя (например, игры в чате).
Код AlexViet не импортирует, не загружает и не обрабатывает их во время работы.
Они не включены в JavaScript-бандл, precache PWA или service worker.
В текущем проекте service worker и механизм precache отсутствуют.
При добавлении PWA-кеширования в будущем исключайте `game-data/**` из его списков.

`--check` ничего не записывает и возвращает код 1 при устаревших, пропавших или лишних
`lesson-*.json`. Повторная генерация не меняет файлы при неизменных источниках.
Генератор также проверяет связи уроков, уникальность ID, обязательные переводы,
формулы, типы блоков и размеры строк таблиц до записи файлов.

На сайте путь имеет вид `https://xpkostxp-droid.github.io/AlexViet/game-data/lesson-09.json`.
Для чтения прямо из GitHub используйте путь
`https://raw.githubusercontent.com/xpkostxp-droid/AlexViet/main/public/game-data/lesson-09.json`.
Для игры достаточно сначала прочитать `index.json`, затем только выбранный урок.
